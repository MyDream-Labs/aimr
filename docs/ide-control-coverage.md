# IDE Control — AIMR: покрытие

Сервер `ide` управляет текущим экземпляром IDE через службы Theia. Четыре инструмента: `ide_settings`, `ide_commands`, `ide_extensions`, `ide_layout`.

Статусы: **проверено**, **доступно, не проверено**, **требует обсуждения**, **вне текущего этапа**. Наличие команды в реестре не означает, что проверены её аргументы, контекст и побочные эффекты. Все не перечисленные ниже command ID по умолчанию непроверены; актуальный каталог доступен через `ide_commands` с `action: search`.

| Возможность | API / конкретная операция | Статус / проверка |
| --- | --- | --- |
| Поиск настроек, типы/описания | `PreferenceSchemaService.getSchemaProperties()` | Проверено: live smoke |
| Значения, схемы и переопределения | `PreferenceService.get()/inspect()` | Проверено: live smoke |
| Запись/сброс User | `set()`, JSON Schema через штатный Ajv | Проверено: boolean, неверный тип, reset |
| Запись/сброс Workspace | `set()`, открытое рабочее пространство | Проверено: `editor.tabSize` |
| JSON null как значение | `set` отдельно от `reset` | Проверено: nullable-настройка тестового расширения; null и reset различаются |
| Folder и языковые переопределения | `resourceUri`, `overrideIdentifier` | Требует обсуждения: параметры пока не открыты |
| Поиск команд | `CommandRegistry.commands`, `isEnabled()` | Проверено: поиск и доступность без аргументов; доступность с аргументами проверяется при запуске |
| Команда без аргументов | `workbench.action.toggleStatusbarVisibility` | Проверено: live smoke |
| Открытие настроек | `preferences:open` | Проверено: live smoke |
| Команды с JSON-аргументами | `CommandRegistry.executeCommand(id, ...args)` | Доступно, не проверено: общей схемы аргументов нет |
| Контекстные/интерактивные команды | Штатные обработчики и диалоги | Требует обсуждения: зависят от фокуса/выделения, могут ожидать пользователя |
| Каталог расширений | `VSXRegistryService.search()` | Проверено: две страницы запроса theme в настроенном реестре |
| Установленные расширения | `PluginServer.getInstalledPlugins()/getUninstalledPlugins()` | Проверено: live smoke |
| Установка по ID/версии | `VSXExtension.install()` | Доступно, не проверено: штатные совместимость, trust/verification dialogs |
| Локальный VSIX | `workbench.extensions.installExtension(URI)` | Проверено: временный declarative VSIX |
| Удаление | `PluginServer.uninstall(versionedId)` | Проверено: удаление тестового VSIX |
| Enable / disable | `PluginServer.enablePlugin()/disablePlugin()` | Проверено: тестовый VSIX |
| Встроенные расширения | Защита Theia / проверка backend metadata `PluginType.System` | Вне текущего этапа: удаление запрещено; compiled Theia extensions требуют сборки |
| Состояние/активация вкладок | `ApplicationShell.widgets/getAreaFor()/activateWidget()` | Проверено: live smoke |
| Show / hide панелей | `expandPanel()/collapsePanel()` | Проверено: правая панель и восстановление исходной раскладки |
| Перемещение вкладок | `addWidget(widget, {area})` | Проверено: перенос AI Chat и возврат |
| Pin / unpin / close | Штатные `pin()/unpin()`, `closeWidget()` | Проверено: pin/unpin и close настроек; close закреплённой вкладки требует unpin. Save-dialog доступен, не проверен |
| Ещё не созданные представления | Штатные команды открытия | Доступно, не проверено: `ide_layout` сам не создаёт неизвестные виджеты |
| Reload / restart | Соответствующие команды Theia | Требует обсуждения: соединение может оборваться до ответа, автоматического восстановления операции нет |
| Несколько MCP-клиентов / окон | Штатная адресация frontend | Вне текущего этапа: один клиент/одно управляемое окно; новый клиент закрывает предыдущий transport |
| Координаты/размеры внешнего окна | Electron main | Вне текущего этапа |

## Контракт

- Поиск/списки: `query`, `limit` (20 по умолчанию, 1–100), `offset` (целое ≥ 0). Ответ: `items`, `hasMore`, `nextOffset`; `total` для локальных каталогов. При смене запроса offset сбрасывается. Настройки/команды сортируются по ID до пагинации; реестр расширений использует свою сортировку/пагинацию.
- Валидация настроек использует исходные схемы и ссылки из `JsonSchemaDataStore`; недоступная схема приводит к ошибке без записи значения.
- Ответы: `status: success | cancelled | requires_reload | error`. Команды могут возвращать только подтверждение завершения обработчика; результат следует проверять через чтение состояния. Native dialogs остаются за Theia.
- Codex получает адрес и Electron cookie текущего процесса; `~/.codex/config.toml` не меняется. Вызовы локального `ide` предодобрены для делегированного управления IDE; это не меняет sandbox/approval policy shell-команд или других MCP-серверов.
- Один штатный MCP-транспорт с небольшим DI override для последовательных клиентов. При обновлении Theia проверить возможность удалить override и адаптер Codex.

## Проверки

`yarn workspace aimr-product-ext test` после сборки: DI и пагинация без модели. С `AIMR_MCP_URL` и `AIMR_MCP_COOKIE` выполняются live smoke во временном Electron-профиле с открытой временной папкой: настройки User/Workspace, команда, вкладки/панели, локальный VSIX и повторное соединение. Значения и раскладка восстанавливаются, тестовое расширение удаляется.

Сценарии описаны в `theia-extensions/aimr-product/test/mcp.spec.mjs`. Не добавлять сюда полный статический каталог команд; новые проверенные сценарии и ограничения отмечать по мере проверки.

Проверка чистого контекста Codex: новый thread самостоятельно выбрал сервер `ide` и выполнил шесть MCP-вызовов для поиска настройки строки состояния, чтения, изменения, проверки и восстановления переопределения. Подсказка не содержала имён сервера/инструментов или command ID.
